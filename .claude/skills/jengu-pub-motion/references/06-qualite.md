# 06 · Check-list qualité (à cocher avant livraison)

## Message
- [ ] L'accroche arrête le pouce en < 2 s (testée sans le son).
- [ ] Un seul bénéfice, compris en une vue.
- [ ] Aucune promesse, aucun prix ni chiffre non confirmé ; aucun logo tiers.
- [ ] CTA lisible ≥ 3 s, numéro / lien exacts (WhatsApp +237 672 705 729).

## Ancrage local
- [ ] Décors, casting, tenues et objets reconnaissables comme Douala / Cameroun.
- [ ] Verbatim : 80/20, test des 3 questions passé (grand-mère · élève · enseignante).
- [ ] Aucun cliché, aucune moquerie, rien de politique ou religieux.

## Image et mouvement
- [ ] Rien d'important dans les zones sûres (250 px haut / 400 px bas en 9:16).
- [ ] Textes ≥ 48 px, contraste suffisant, aucun mot coupé, max 2 polices + 1 accent.
- [ ] Aucune interpolation linéaire ; entrées multi-propriétés, décalées ; sorties plus rapides.
- [ ] Pas plus de 3 s sans nouvel élément ; un seul point focal à la fois.
- [ ] Captures d'écran de l'app nettes et à jour ; logo non déformé.
- [ ] Images vérifiées à 0/25/50/75/100 % de chaque scène.

## Son
- [ ] Voix intelligible partout (≈ 8 dB au-dessus de la musique), noms bien prononcés.
- [ ] Musique libre de droits, licence vérifiée et notée dans le dossier.
- [ ] Niveau final ≈ −14 à −16 LUFS, crête ≤ −1,5 dBTP.

## Livraison
- [ ] Formats : 9:16 (+ 1:1 / 4:5 si demandé), durées 15 / 30 / 60 s.
- [ ] Poids raisonnable (< 50 Mo pour WhatsApp), H.264 + AAC, faststart.
- [ ] Textes de publication fournis (WhatsApp, Facebook, TikTok, LinkedIn).
